# Without-love - a creative coding challenge

At WeAreDevelopers, we love to code. We love the concept of creating something from nothing, finding a solution for a problem and create something people can get excited about. 

That's why we thought we'd give you a challenge to show what you can do with an [HTML document](without-love.html) containing some wisdom by Lao-Tzu about what several concepts become when love is missing. 

We've used this to learn about some new(ish) things in CSS we hadn't played with before and we encourage you to use this as an opportunity to try out something new. 

**There are no rules what you do with this and what tech you use**. 

* We will pick three winners in the next few weeks 
* We will invite to a special edition of [Coffee With Developers](https://www.wearedevelopers.com/coffee-with-developers) to talk about their submissions. This means that of course you can use AI to create your submission, but we also want you to be able to explain what you've done and why it works.
* All winners get a free ticket to one of our events, either in [Berlin](https://www.wearedevelopers.com/world-congress), [Bengaluru](https://www.wearedevelopers.com/conference-india) or [San Jose](https://www.wearedevelopers.com/world-congress-north-america).  

**You can submit your solution as a pull request here - simply create a folder with your name and code in the entries folder**.

* [Here are all the submissions so far](https://codepo8.github.io/without-love/entries/index.html) - to start, Chris Heilmann added a [text mover](https://codepo8.github.io/without-love/entries/wo-mover.html) and a [simple shuffle effect](https://codepo8.github.io/without-love/entries/wo-shuffle.html).

Show the world what adding some love can do.
